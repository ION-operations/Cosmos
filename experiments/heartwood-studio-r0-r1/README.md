# Heartwood Studio R0/R1 Scaffold

This folder is the first organized app scaffold for the Heartwood procedural tree engine inside the Cosmos repository on branch `GPT`.

## Purpose

Replace monolithic HTML iteration with a controlled procedural-botany lab:

- aspect workbenches
- graph-authoritative tree structure
- reference oracle
- validation gates
- raw WGSL/WebGPU runtime contract

## Structural gates in this slice

- `graph_authority_gate` — every rendered branch/root/twig must correspond to a `TreeNode`.
- `leader_continuity_gate` — trunk is order-0 `Leader`, not a capped primitive.
- `endpoint_state_gate` — every terminal has a biological endpoint state.
- `flat_cap_gate` — arbitrary flat caps are rejected.
- `junction_continuity_gate` — branch unions use `UnionZone`, not blob inflation.

## Run

```bash
cd experiments/heartwood-studio-r0-r1
npm install
npm run dev
npm test
```
