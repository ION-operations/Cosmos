# Heartwood Studio R0/R1 — Orchestration Blueprint

Heartwood Studio is a procedural-botany lab, not a single tree renderer.

Each workbench perfects one biological truth in isolation, proves it against references and validation gates, then promotes into the full tree view.

## Stack

- React + TypeScript + Vite for studio shell.
- R3F / Three for viewport orchestration, cameras, debug overlays, and picking.
- Raw WebGPU / WGSL for validation, procedural buffers, and future geometry/material/wind passes.
- TreeGraph and species profiles as CPU-side authority.
- WGSL mirrors the authority into typed buffers; it does not invent tree truth.

## First vertical slice

R0/R1/R2 proves:

1. Studio shell.
2. Reference Oracle.
3. TreeGraph authority.
4. Trunk-as-Leader.
5. Endpoint taxonomy.
6. Branch Architecture workbench.
7. Junction / Collar workbench.
8. WebGPU/WGSL smoke contract.
9. Structural validation gates.

## Deferred until structural truth passes

- final bark realism
- foliage systems
- soil coupling
- FlowGuide-MPM
- cut-cap interiors
- fire/snow/seasons
- rigid-body debris

These are not rejected. They are blocked until skeleton, endpoint, Leader, and UnionZone gates are stable.
